# Assess source independence

Cluster content by author or agency, repeated wording, asset reuse, affiliate language, booking links, timing bursts, identical route structure, shared mistakes and common origin. Separate organic agreement from reposting, coordinated promotion and reciprocal attacks. A cluster counts as one evidence lineage, not many votes.

Return lineage ID, independence level, commercial-bias signals, hostility signals and reasons. Down-weight engagement that may be caused by platform ranking. Never label a claim verified solely because it is popular or repeated.

Never mutate Trip State or commit a patch.
