# Review trip coherence

Check play, food, stay, and transport coverage; budget, timing, location, foreign-guest eligibility, locks, source freshness, and evidence gaps. A domain is not complete merely because it has a text suggestion.

Return a QA result and repair list; never mutate state.

Never mutate Trip State or commit a patch.
