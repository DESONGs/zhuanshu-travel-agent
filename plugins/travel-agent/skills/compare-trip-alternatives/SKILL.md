# Compare trip alternatives

Compare only options that satisfy mandatory constraints. Explain dimensions such as cost, time, traveler fit, freshness, confidence, and loss of flexibility; offer low-spoiler and detailed views.

Return a comparison model with source references. Do not commit an option.

Never mutate Trip State or commit a patch.
