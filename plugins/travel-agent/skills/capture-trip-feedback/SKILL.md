# Capture trip feedback

Preserve consent and attribution. Do not promote one person’s experience into a public destination fact without independent review. Route long-lived public-claim candidates to the read-only curator.

Return feedback classification and memory candidates. Never write destination memory directly.

Never mutate Trip State or commit a patch.
